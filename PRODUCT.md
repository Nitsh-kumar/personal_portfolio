## Platform

web

## Users

Technical recruiters, engineering leads, and hiring managers evaluating candidates for full-time Generative AI / LLM Engineer roles. They are screening portfolios quickly to verify genuine technical depth, architectural understanding, and hands-on ability to build and deploy practical AI systems rather than superficial wrapper tutorials.

## Product Purpose

Serve as the definitive professional showcase for Nitish Kumar. The site exists to turn visitor curiosity into interview invitations and technical conversations by demonstrating proven competence in autonomous agent frameworks, RAG pipelines, and modern model integrations.

## Positioning

A production-focused AI engineer who designs and deploys functional LLM systems, RAG pipelines, and cutting-edge Model Context Protocol (MCP) integrations (such as GPTCraft) backed by solid full-stack infrastructure (FastAPI, React/Next.js, Python).

## Operating Context

Desktop and mobile web browsing by busy technical evaluators, frequently accessed via resume links, LinkedIn profiles, or direct referrals. Evaluators scan for live project demos, architecture highlights, clean code repositories, and direct channels to schedule an interview or reach out.

## Capabilities and Constraints

- Single-page portfolio application with smooth section navigation (Work, About, Skills, Contact).
- Interactive project showcase with direct links to live products (e.g., https://gptcraft.in/) and GitHub repositories.
- Contact interface with immediate access via email, LinkedIn, GitHub, and WhatsApp.
- Technical constraint: Must remain high-performance, fast-loading, and responsive across all device sizes.

## Product Principles

1. **Proof Over Hype**: Lead with verifiable code, architectural clarity, and working systems rather than buzzwords.
2. **Immediate Technical Scannability**: Ensure evaluators can grasp core competencies, stack fluency, and project scope within seconds of arrival.
3. **Frictionless Engagement**: Every path through the portfolio should seamlessly guide the evaluator toward verifying work and initiating contact.
4. **Architectural Substance**: Treat every project feature as an opportunity to demonstrate production-grade AI thinking (scalability, latency, error handling, tool use).
